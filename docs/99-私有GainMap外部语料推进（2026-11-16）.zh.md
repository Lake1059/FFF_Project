## 关键技术事实（本轮新增）

### 1. tmap flags 判别位 0x40（SDR vs HDR base）
- **锚件**：
  - `seine_sdr_gainmap_srgb.avif`：tmap flags = **0xc0** → SDR base，施加增益图
  - `seine_hdr_gainmap_srgb.avif`：tmap flags = **0x80** → HDR base，不施加
- **规则**：bit 7 (0x80) 为格式标识，bit 6 (0x40) = `useBaseColorSpace`。
  - `0xc0 = 0x80 | 0x40`：SDR base（base 就是 SDR，增益图把 SDR 抬到 HDR）
  - `0x80 = 0x80 & ~0x40`：HDR base（base 本身已是 HDR，增益图描述两个 HDR 编码之间的转换）
- **判定条件**：仅当 `(flags & 0x80) && !(flags & 0x40)` 时判 HDR base。flags=0x00 不判 HDR（格式未知）。
- colr transfer 仅作兜底，tmap 有效时优先用 tmap flags。

### 2. JPEG ISO APP2 flags 偏移 = URN 起始 + 32
- APP2 ISO box 布局：
  - payload[0..26] = `"urn:iso:std:iso:ts:21496:-1"`（27 字节）
  - payload[27] = NUL
  - payload[28..29] = min_version u16
  - payload[30..31] = writer_version u16
  - **payload[32] = flags u8**
- 退化 `"1\0"` 布局（skia 测试件）：min_version 可能为 1 而非 0，但 flags 偏移不变。
- bit6 (0x40) = useBaseColorSpace：0xc0 → SDR base（施加），0x80 → HDR base（不施加）。

### 3. grpl/altr 组实体顺序必须「增益图侧在前、主色图在后」
- `meta/grpl` box 结构：FullBox(4字节) + group_id u32 + num_entities u32 + entities u32[]。
- **规则**：如果 altr 组同时包含 primary 图和增益图侧（tmap/gainmap item），
  - 正确顺序 `[gainmap, primary]` → 增益图有效，施加
  - 错误顺序 `[primary, gainmap]` → altr 分组无效，**忽略增益图（not_gainmap）**
- **锚件**：`seine_hdr_gainmap_wrongaltr.avif` entities=[1,2]（primary=1 在前）→ not_gainmap；
  `seine_hdr_gainmap_srgb.avif` entities=[2,1]（tmap=2 在前）→ applied。
- 没有 grpl/altr 的文件不受影响。
