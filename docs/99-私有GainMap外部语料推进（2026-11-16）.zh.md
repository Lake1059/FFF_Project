## 本轮完成项

### P0：外部 AVIF 底图解码
- **根因**：AV1 raw OBU 的 FFmpeg demuxer 名应为 `"obu"` 而非 `"av1"`。
- **效果**：`seine_sdr_gainmap_srgb.avif`（400×300, AV1, tmap v0）成功解码并施加（p50≈0.757, maxLinear≈2.45）。同组 `big_srgb` 同样通。

### P0：误施加修复
- **gamma=0 拒绝**：`seine_sdr_gainmap_gammazero.avif` 原本静默 gamma→1.0 并施加，现改为 fail-closed（方向正确；bucket 为 unsupported 而非 malformed，待后续对齐）。
- **tmap brand 检查**：`seine_sdr_gainmap_notmapbrand.avif` ftyp 无 `tmap` brand，按 libavif README 忽略增益图，现返回 `not_gainmap`。

### P2：grid 底图组合
- 新增 grid base 路径：解析 grid payload（rows/cols/width/height），通过 dimg 收集 codec tile（跳过 alpha/aux），逐 tile 解码后拼接到 canvas。
- 带完整边界检查防止越界。
- 影响：`color_grid_gainmap_different_grid.avif`、`color_nogrid_alpha_nogrid_gainmap_grid.avif` 从 malformed → decoded_not_applied（base 拼出，但 gainmap grid 组合未做）。

### P2：HDR 底图语义
- PQ/HLG 底图不再返回 fail_closed_unsupported，而是 `decoded_not_applied` + reason "hdr base displayed as-is; gain map not applied"。
- 影响：`seine_hdr_gainmap_srgb/small` 等 8 件。

### P1：Apple 真实件接线
- 接入 `GainMapAppleMeta.h`（命名空间 `gainmap_apple`），替换旧 `BuildAppleMeta` 近似公式。
- MakerNote 解析新增 type=10（SRATIONAL，两个有符号 int32）支持。
- **实测 `apple_hdr_sample_imazen.heic`**：
  - verdict=applied, base 1512×850, gainmap 756×426 单通道 8-bit
  - headroom=**7.37172**（与预期 7.371721 精确匹配）
  - meta.source=**makenote**（非 xmp 近似）
  - m33=117926/114993=1.025506, m48=769/456192=0.001686, stops=2.882
